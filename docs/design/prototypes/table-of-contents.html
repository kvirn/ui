TableOfContents: the chosen look

A throwaway prototype for the design spec. The contents list shares Navigation’s item rules:

  • weight 400 at rest, and an underline on hover;
  • a solid primary row for the heading being read (aria-current="location");
  • the quiet fill at weight 600 for the headings above it.

The title is the page’s own heading, with the heading-4 look, and it names the list with aria-labelledby. There’s no script, so “Avgifter” is forced as current. The links still jump to their headings.

  • Forced colours: in Chrome or Edge DevTools, open Rendering and set “Emulate CSS media feature forced-colors” to “active”.
  • Reflow: the Finnish page is as wide as the content of a 320px screen.
