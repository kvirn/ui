Navigation links: the current page and the active trail

A throwaway prototype for the design spec. It has two parts:

  • Four ways to mark the current page (A–D). The maintainer chose C, with T3, on 2026-10-05. The horizontal bar is in its own prototype.
  • Three active-trail treatments (T1–T3), each drawn with B and with C. The spec recommends C with T3.

“Today” is drawn by the real theme.css. Each option is unlayered CSS on top of it, written as it would go into theme.css section 8. Every option shares S1–S4 from the spec: weight 400 at rest, an underline on hover, no border on the item, and a straight LinkText bar in forced colours.

  • Each current-page option has a light and a dark panel. The table forces every state, on canvas and on surface. The sidebar next to it is live: hover, press and Tab through it.
  • Each trail treatment has four panels (B and C, light and dark). Each holds a live tree four levels deep, with the current page at level 3, and the same tree with hover and focus forced.
  • Forced colours: in Chrome or Edge DevTools, open Rendering and set “Emulate CSS media feature forced-colors” to “active”.
  • Reflow: the Finnish sample is as wide as the content of a 320px screen. Narrow the window to 320px to see the whole page reflow.
  • Reduced motion: no option adds motion.

Today: the current theme.css

What looks off, checked against theme.css section 8 (the spec, section 2):

  1. The bar is a crescent. A 4px border-inline-start on an 8px radius follows both corners and tapers to nothing. In light, the focus ring is the same lavender and runs 2px outside it.
  2. The weight barely marks the current page. 500 at rest and 600 when current is one step: all the labels look equally heavy.
  3. Three surfaces. Storybook’s wrapper is a rounded box with a hairline on all four sides, so it looks like a card. Navigation adds a pill and the crescent for one state, plus a pill on hover. The sidebars below are square, like the docs site’s.
  4. You can’t see hover, and the rows look like slabs. The surface-raised hover is 1.00:1 on the light canvas and 1.06:1 on surface.

A. Straight bar (not chosen)

Keep today’s tint, and draw the bar as a straight 4px mark inside it, so the pill and its mark read as one shape.

Fixes
The crescent (1), the weight (2) and hover (4). The surfaces (3) in part: the pill appears only on the current page.
Current page
The bar (a shape), weight 600 and the tint, plus aria-current.
Indicator, 3:1
primary on primary-subtle: 4.15 / 3.32 / 8.72 / 8.33 (light / dark / light contrast / dark contrast). Already in theme:check.
Risk
The least change to the look. The tint and the bar stay two layers of one shape.
Cost
About 25 lines in theme.css section 8. No new token, class or pair.

First-round pick: A, Straight bar (superseded)

Kept as the record. The first round recommended A, which kept the approved look and changed only what failed. The maintainer then ruled out A and D and shortlisted B and C, so the recommendation now sits with the active trail below.

Active trail: three treatments, each with B and C

The maintainer kept B and C, ruled out A and D, and asked to see the trail to the current page in CMS navigation: “either by lines or arrows marking path or just by indicating the path ending up to the current active item”.

What a trail must tell, strongest first (the spec, section 12):

  1. Where am I: the current page, always the strongest mark.
  2. Which branch I’m in: every ancestor up to the top level, marked on its own row, and told apart from an open group off the path and a collapsed group.
  3. How deep: the 16px indent per level. The trail steps with it.

Emphasis: current, then trail, then the rest. Under B the current page is quiet, so the trail needs a channel other than tint or weight. Under C it’s loud, so the trail must stay quieter. The trail is found with CSS :has() (no API change), and aria-current="page" stays on the current link only.

T1. Connector line (not chosen)

A 1px line runs down each sub-list on the trail, past the siblings above the trail item, and turns into it with an elbow. The last elbow points at the current page.

Seed
“lines”, and “an elbow connector that ends at the current item”.
With B
A primary line. The elbow at the end gives B’s quiet current page a shape.
With C
A secondary line, quieter than the solid fill.
Strength
It visibly joins each ancestor to its trail item, past every sibling.
Limits
The line goes when the trail branch is collapsed (the last stress case). At 1px it’s the thinnest mark of the three.
Cost
About 35 lines in theme.css section 8. No new token, class or API.

T2. Signpost arrows (not chosen)

A small down arrow at the start of every ancestor row: the way to your page goes down here. The current page has none, because it’s where the arrows lead.

Seed
“arrows marking path”.
Why down
chevron-down already means “open”, and chevron-forward is the breadcrumb separator. A sideways arrow reads as “go”. A down arrow doesn’t mirror, only its place does.
With B / C
primary arrows / secondary arrows.
Limits
A small mark, which some may read as “expand”. It doesn’t join an ancestor to its trail item across siblings.
Cost
About 30 lines. Drawn with two pseudo-elements: the built-in icons can’t be used from CSS.

T3. Marked path (chosen, with C)

Every ancestor row gets a lighter version of the current page’s look: the path ending at the current page.

Seed
“just by indicating the path ending up to the current active item”.
With C
Ancestors get the quiet fill and weight 600, and the current page is the solid fill. The quiet fill marks the way, the solid fill the end.
With B
Not viable. Ancestors at 600 look the same as the current page, except for a 1.07:1 tint. It’s shown so the failure can be seen.
Forced colours
Weight only, because the tint drops.
Cost
About 8 lines, and no geometry for long words, 320px or RTL to break.

Chosen pairing: C with T3 (maintainer, 2026-10-05)

The solid fill marks the current page, the quiet fill and weight 600 mark every ancestor, and the rest stays plain. It’s the clearest ranking: solid, then quiet fill and bold, then plain. It adds no geometry for long labels, 320px, RTL or compact density to break, and a collapsed trail branch stays marked. It costs about 8 lines of theme.css on top of C, with no API change. If testing shows that C’s solid row is mistaken for keyboard focus, the fallback is B with T1.
