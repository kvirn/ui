Public-service components, with the evidence beside them. KvirnUI is a headless React library for public services in the Nordics and the EU, designed and tested to meet WCAG 2.2 AA.

Pre-alpha. The API will change. Testing with assistive technology is pending.

KvirnUI in numbers

  • 56documented components and hooks, from a skip link to a data table.
  • 6languages: Swedish, Finnish, Norwegian Bokmål and Nynorsk, Northern Sámi and English. Much of the Sámi text is still English.
  • 4themes: light and dark, each with a high-contrast version.
  • 3runtime dependencies, all from TanStack.
  • 0lines of CSS in the headless packages. One import adds the theme.
  • 0cookies, trackers or calls home, here and in the library.

The transcripts are examples written by hand. Real screen readers use their own words. The role words come from KvirnUI's strings in the chosen language.

For developers

A hook when you want control, a component when you want speed. The same contract either way.

Hook

const disclosure = useDisclosure()

<button {...disclosure.triggerProps}>
  Show the answer
</button>
<div {...disclosure.panelProps}>…</div>

Component

<Disclosure.Root>
  <Disclosure.Trigger>
    Show the answer
  </Disclosure.Trigger>
  <Disclosure.Panel>…</Disclosure.Panel>
</Disclosure.Root>

pnpm add @kvirn-ui/react @kvirn-ui/i18n

Remove the theme import and everything unstyles. Keep it and change the tokens. Either way, state is data-* and the markup is yours.

How we know it works

  • Native HTML first

    A button is a <button>. We add ARIA only where HTML falls short.

  • A contract for every component

    Roles, focus, announcements and every key, written down and shown on its page.

  • Every key, tested

    Each key in a contract has a test that presses it in a real browser.

  • Checked in every theme

    Every story is checked with axe in all four themes.

  • What a screen reader says

    For more and more components, tests check what a virtual screen reader reads, and in which order.

  • Pending means pending

    Testing with real assistive technology comes next. Until people have done it, we say pending.
