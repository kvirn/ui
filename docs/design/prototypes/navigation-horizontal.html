Navigation: the horizontal bar and the chosen look

A throwaway prototype for the design spec, sections 12 to 13. It shows the look the maintainer chose:

  • C, the current page as a solid fill;
  • T3, its ancestors in the quiet fill at weight 600;
  • weight 400 at rest and an underline on hover;
  • a horizontal bar made with kv-navigation--horizontal.

“Today’s” rules in theme.css are overridden by unlayered CSS that mimics Plan 0047’s section 8.

  • Forced colours: in Chrome or Edge DevTools, open Rendering and set “Emulate CSS media feature forced-colors” to “active”. The current item’s bar moves to the bottom in a bar.
  • Reflow: the Finnish bar is as wide as the content of a 320px screen. Narrow the window to see the whole page reflow.
  • Reduced motion: nothing here adds motion.

A bar next to a sidebar (spec 13.6)

Two navigations, each named and each with one aria-current. The bar marks the section with aria-current="true", because the page isn’t in it. The sidebar marks the page with aria-current="page". “Bygglov” is a collapsed group, rendered with hidden. The left column shows the approved rule, where every aria-current is solid. The right column shows Q-N2, where true takes the trail look.
