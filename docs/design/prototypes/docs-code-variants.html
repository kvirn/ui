Docs code block: four variants

The same example in each: a 27-line TSX sample, the disclosure "Code, 27 lines", the language and Copy code. Each variant shows closed, closed after a copy, open at 40rem with long lines that scroll (Tab to the code to scroll it with the arrow keys), and 320px open after a refused copy. Buttons are compact (32px) in the wide frames, as the docs chrome from 64rem, and 44px in the 320px frame. Every button works.

A. Slim strip

Structure
The bar stays under the preview but becomes a thin strip in the code's own colour (surface), so the strip and the code read as one object. The toggle is the quiet Disclosure trigger (text and chevron), the language sits right after it as metadata, and Copy code is the one compact button.
Trade-off
The smallest change and the calmest bar. The quiet toggle is plain text with a chevron until hovered, so a first-time reader leans on the chevron and the line count to see it opens something.
Tab order
Code toggle, Copy code, the code (only while it scrolls).

B. Title bar

Structure
The file name moves from the top of the card to a title bar between the preview and the code, like an editor tab, with the language as a small tag. Code and Copy code are one attached pair of compact buttons at the end.
Trade-off
The file name names the code it sits on, and the card loses a band. But an attached pair can look like a segmented choice, and the preview has no title at its top, so the figure leans on its section heading.
Tab order
Code toggle, Copy code, the code (only while it scrolls).

C. Copy first, full-width toggle

Structure
Copy code comes first, as the task most readers came for. The rest of the row is the toggle, a full-width accordion row with the chevron at the end. The language joins the file name in the header, so nothing floats in the bar.
Trade-off
The biggest, clearest target and a familiar accordion row. It swaps the spec's Tab order (Copy before the toggle) and makes the bar a full-width band again, though a quiet one.
Tab order
Copy code, Code toggle, the code (only while it scrolls).

D. One header

Structure
All the chrome goes into one header above the preview: file name and language at the start, Code and Copy code at the end. Closed, the card ends with the preview; open, the code attaches under it.
Trade-off
The calmest closed state, with one row of chrome. But the toggle sits a whole preview away from the code it opens (on a phone the code can open out of view), and Tab goes through the example's own controls before it reaches the code.
Tab order
Code toggle, Copy code, the example's controls, the code (only while it scrolls).
