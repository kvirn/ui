Tabs

A row of tabs that shows one panel at a time, for content people switch between on the same page, such as the parts of a case.

Package
@kvirn-ui/react
Pattern
APG Tabs
Testing with assistive technology
Pending

On this page

  • When to use it
  • Example
  • Use cases
  • Accessibility
  • Keyboard
  • API reference

When to use it

  • For two to six views of one thing, where people compare or switch, such as Details, Documents and History of a case.
  • Not for steps in a form: use Stepper.
  • Not for links to other pages: use Navigation.

Example

DetailsDocumentsHistory

Case 2026-0412 · Building permit · Received 3 October

import { Tabs } from '@kvirn-ui/react'

<Tabs.Root label={t('case.tabs')}>
  <Tabs.List>
    <Tabs.Tab value="details">{t('case.details')}</Tabs.Tab>
  </Tabs.List>
</Tabs.Root>

Use cases

The parts of a case, in a staff tool

Each tab is one view of the same case. The selected tab is kept in the address, so a reload or a shared link opens the same view.

Accessibility

Tabs follow the APG Tabs pattern with automatic activation. The list is one Tab stop; the arrow keys move between tabs.

Keyboard

KeyWhereWhat it does
TabPageMoves to the selected tab, then to the panel
→ ←A tabSelects the next or previous tab
Home EndA tabSelects the first or last tab

API reference

Tabs.Root

Holds the selected value and names the list.
