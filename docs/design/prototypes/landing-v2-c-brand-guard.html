Why the guard matters

Tokens are named by role, never by hue, so a rebrand is a few lines. The guard runs the same contrast maths as our release check, so those lines cannot quietly break AA.

  • 56documented components and hooks.
  • 6languages. Much of the Sámi text is still English.
  • 4themes: light, dark, each with high contrast.
  • 3runtime dependencies, all from TanStack.
  • 0lines of CSS in the headless packages.
  • 0cookies, trackers or calls home.
