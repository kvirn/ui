## Theme and docs

**Docs site goal ([Plan 0053](plans/0053-docs-as-municipality-site.md)).** `apps/docs` is a docs site first, and it is also a reference municipality website: the page types, layouts, blocks and patterns a Nordic municipality needs, built from KvirnUI as an adopter would.
