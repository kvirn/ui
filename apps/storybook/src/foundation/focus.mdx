# Focus

Where focus is, where it goes and where it comes back to. This page has three parts: the ring that shows it, how to move, hold and return it in your own widget, and how to move it when the page or a step changes.

**The ring.** Every focusable component gets the same ring: 2px solid `focus-ring`, 2px outside the element, following its radius. It shows for keyboard focus only, and it is restyled, never removed.

## Tokens

| Token                    | Value                                                    | Use                                      |
| ------------------------ | -------------------------------------------------------- | ---------------------------------------- |
| `--kv-focus-ring-width`  | `2px`                                                    | The thickness of the ring                |
| `--kv-focus-ring-offset` | `2px`                                                    | The gap between the element and the ring |
| `--kv-color-focus-ring`  | A step of the primary scale, which differs in each theme | The ring colour                          |

The ring colour is `primary-500` in light, `primary-400` in dark, `primary-800` in light high contrast and `primary-200` in dark high contrast. In forced colours it is the system colour `Highlight`.

## Using the ring

- **It shows for keyboard focus only.** The ring uses `:focus-visible`, or the `data-focus-visible` attribute a component sets. A mouse click doesn't show it.
- **It sits outside the element.** The 2px offset puts the ring against the page, not on the element. On a filled button, the ring colour and the fill are close, so a ring drawn on the fill could vanish. Outside, it has 3:1 against the background next to it.
- **A custom component gets the same ring.** Add `data-focus-visible` to force it on, for example in a story or a test.
- **Don't write `outline: none`.** If a design needs another look, restyle the ring with the tokens. Never remove it.

## Ring accessibility

- **Focus visible (2.4.7).** Every focusable element shows where focus is.
- **Focus appearance (2.4.13).** The ring is at least 2px thick and has 3:1 contrast against the colours next to it. `theme:check` measures `focus-ring` against every background it is used on, including the panel and status backgrounds, in all four themes.
- **Not obscured (2.4.11).** A sticky header or action bar must never cover the focused element. Set `scroll-padding` to match its height.
- **Forced colours.** The ring is `Highlight`, so the user's own palette decides the colour.
- **Scroll regions.** A scrollable region is focusable so keyboard users can scroll it, so it shows the ring too (2.1.1).

## Customising the ring

Override the width and offset on `:root`. To change the colour, set a semantic token per theme, and run `vp run theme:check` or `checkThemeCss()`, which measures the ring against every background it's used on. A thinner ring or a glow isn't used, because it fails 2.4.13.
