# @kvirn-ui/i18n

KvirnUI message catalogs for Swedish, Finnish, Norwegian (Bokmål and Nynorsk), Sámi and English. `@kvirn-ui/react` uses it for every visible and announced string.

```tsx
import sv from '@kvirn-ui/i18n/sv'
```

Each locale is its own entry (`en`, `sv`, `fi`, `nb`, `nn`, `se`), so a bundler only includes the ones you import.
