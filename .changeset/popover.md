Popover, with the overlay mechanism the floating components share (Plan 0022). A button that opens a small non-modal panel in the browser's top layer, placed next to the button.

- `@kvirn-ui/core`: `computePlacement(anchorRect, popupSize, viewport, options)`, a pure placement function that flips to the other side, shifts to stay inside the viewport, limits `maxHeight` to the room left and never covers the anchor, with logical `start` and `end` sides for right-to-left text. `createDismissableLayerStack()`, the pure stack behind Escape and outside presses, where only the top layer reacts. Types: `Placement`, `PlacementOptions`, `ComputedPlacement`, `OverlayRect`, `OverlaySize`, `DismissableLayerStack`, `DismissableLayerOptions`, `LayerTargetCheck`.
- `@kvirn-ui/react`: `Popover.Root`, `.Trigger`, `.Popup` and `.Close` (also `PopoverRoot`, `PopoverTrigger`, `PopoverPopup`, `PopoverClose`) and the hook `usePopover({ open, defaultOpen, onOpenChange, placement, offset, padding, matchAnchorWidth })`, which returns `isOpen`, `placement`, `triggerProps`, `popupProps` and `closeProps`. The trigger gets `aria-expanded`, `aria-controls` and `aria-haspopup="dialog"`. The popup is `<div popover="auto" role="dialog">`, which you name with `aria-label` or `aria-labelledby`. Escape and a press outside close it and return focus to the trigger, and opening never moves focus. `onOpenChange(open, { reason, event })` reports `'trigger-press'`, `'close-press'`, `'escape'`, `'outside-press'` or `'light-dismiss'`. The shared hooks are public too: `usePopup({ open, anchorRef, popupRef, placement, offset, padding, matchAnchorWidth, popover, onNativeDismiss })`, which applies the native `popover` attribute, places the popup with inline `position: fixed` and sets `data-open`, `data-placement`, `--kv-popup-width`, `--kv-popup-max-height` and `--kv-anchor-width`, and `useDismissableLayer({ open, onDismiss, ref, ignore })`, which reports `'escape'` or `'outside-press'` for the top layer only. Types: `Popover*Props`, `PopoverState`, `PopoverChangeDetails`, `PopoverChangeReason`, `Popover*PartProps`, `UsePopoverOptions`, `UsePopoverResult`, `UsePopupOptions`, `UsePopupResult`, `PopupPartProps`, `Placement`, `UseDismissableLayerOptions`, `DismissReason`. No strings of their own, no CSS: the default theme doesn't style Popover yet.
