Add Table, a native `<table>` with TanStack Table bundled (Plan 0026). Alpha.

- `@kvirn-ui/core`: `createTable(options)` wraps TanStack Table's `constructTable` with the store reactivity bindings and returns `{ table, store, updateOptions }`: `store` is the table's state as a `ReadableStore`, and `updateOptions` hands the instance each render's options without notifying subscribers. `enableMultiSort` is always `false` and passing it is a type error. `createLocaleSortFn(locale, collatorOptions?)` sorts text with `Intl.Collator`, so å, ä and ö come after z in Swedish, Finnish and Norwegian, and numbers and dates sort by value. `renderTemplate(template, context)` renders a column's `header`, `cell` or `footer`. Curated re-exports of TanStack Table, the only way it is exposed: `tableFeatures`, `createColumnHelper`, the sorting, row selection, expanding, pagination, column and global filtering and column visibility features, `createSortedRowModel`, `createFilteredRowModel`, `createPaginatedRowModel` and `createExpandedRowModel`, the built-in `sortFn_*` and `filterFn_*` functions, and the types `ColumnDef`, `Row`, `Cell`, `Header`, `HeaderGroup`, `Column`, `SortingState`, `RowSelectionState`, `ExpandedState`, `PaginationState`, `ColumnFiltersState` and more. TanStack's `Table` type is `TanStackTable`.
- `@kvirn-ui/react`: `Table` (also `Table.Root`, `.ScrollRegion`, `.Caption`, `.Head`, `.Body`, `.Foot`, `.Row`, `.ColumnHeader`, `.RowHeader`, `.Cell`, `.SortButton`, `.SelectCheckbox`, `.SelectAllCheckbox`, `.ExpandButton`, `.DetailRow` and `.Empty`, each also a named export such as `TableRoot`) and `useTable(options)`. The parts are plain native elements without `table`, so a small static table needs no TanStack Table. With the result of `useTable`: `aria-sort` on the sorted column only and a polite announcement for each sort, row checkboxes named by their row header ("Select Anna Svensson") or number, `data-selected` and never `aria-selected`, an indeterminate select-all that announces the count, expand buttons with `aria-expanded` and `aria-controls`, `aria-busy` and `Table.Empty`, and the filtered row count announced after 500 ms. `virtualize` renders only the rows near the scroll position between `aria-hidden` spacer rows, with `aria-rowcount` and `aria-rowindex`, the focused row kept rendered and the sticky header's height as the scroll padding. `Table.ScrollRegion` is a named region and a Tab stop only while the table scrolls. `useTable` options: TanStack Table's, plus `rowHeader`, `virtualize`, `isLoading` and `messages`. The TanStack Table re-exports of `@kvirn-ui/core` are exported too, so nothing else is installed.
- `@kvirn-ui/i18n`: the `table` namespace in all six locales: `sortedAscending`, `sortedDescending`, `sortCleared`, `selectRow`, `selectRowNumber`, `selectAllRows`, `selectedCount`, `rowCount`, `loading`, `empty` and `rowDetails`. Northern Sámi starts as English placeholders.
- `@kvirn-ui/theme`: the Table section (design spec `docs/design/table.md`). Native display everywhere, 48px rows (32px in `kv-compact` from 64rem), a filled head that sticks in a height-limited `Table.ScrollRegion` (`--kv-table-scroll-region-max-block-size`, `80svh` when virtualized), a `border-subtle` divider under every row and no stripes, frame or row hover, `primary-subtle` behind a selected row's checked box, inset focus rings on the sort and expand buttons, a static hatched bar on a busy head, numeric columns (`kv-table-column-header--numeric`, `kv-table-cell--numeric`, `kv-table-row-header--numeric`), forced-colours rules and 44px targets on coarse pointers. Prose leaves a `kv-table` alone. `danger`, `success` and `warning` on `primary-subtle` are now measured text pairs.
