OneTimeCode (Plan 0014, Phase 3, ADR-0033). A code from a text message, an email or an authenticator app, shown as a row of boxes over one native `<input>`: SMS autofill, password managers, paste, dictation and undo work on the one field, and the boxes only draw its value, caret and selection.

- `@kvirn-ui/react`: `OneTimeCode.Root`, `.Input` and `.Slot` (also `OneTimeCodeRoot`, `OneTimeCodeInput`, `OneTimeCodeSlot`) and the hook `useOneTimeCode({ pattern, value, defaultValue, onValueChange, onComplete, disabled, announceRejections, messages })`, which returns `rootProps`, `inputProps`, `getSlotProps(index)`, `slots` (one per position of the pattern, `{ kind, character, isFilled, isActive, caret, isSelected }`), `pattern`, `characterCount`, `isComplete` and `isReady`. The code is shaped by a `pattern` (ADR-0045, default `'999999'`): `9` digit, `*` letter or digit, `a` letter, `A` upper-case letter, `&` upper-case letter or digit (all ASCII, lower case typed into `A` and `&` is upper-cased) and `-` a separator drawn as its own `aria-hidden` cell (`kv-one-time-code-separator`, `kind: 'separator'`). `****-****` holds `abcd-1234`, and a paste with or without the dash ends the same. `masks.oneTimeCode({ pattern })` throws a `RangeError` for an invalid pattern. `inputmode="numeric"` is set only when every symbol is `9`. The input is `type="text"` with `autocomplete="one-time-code"`, no `maxlength`, and the `masks.oneTimeCode` mask (a pasted `123 456` or "Your code is 123456" ends as `123456` for `999999`). The slots are `aria-hidden` and take `data-filled`, `data-active`, `data-caret`, `data-selected` and `data-invalid`; the root takes `data-ready`, `data-complete`, `data-invalid`, `data-disabled`, `data-character-count` and `data-separator-count` (always rendered, from the pattern). Nothing moves focus or submits: `onComplete(value, unmaskedValue)` is a callback only (`unmaskedValue` is the code without the dashes). The component adds no strings. Types: `OneTimeCode*Props`, `OneTimeCodeState`, `OneTimeCodeSlotState`, `OneTimeCode*PartProps`, `UseOneTimeCodeOptions`, `UseOneTimeCodeResult`. Development warnings: a Slot or Input outside a Root, a Slot with an index outside the code, an Input with no accessible name, and an Input in a Field without a description.
- `@kvirn-ui/theme`: styles for `kv-one-time-code`, `kv-one-time-code-input`, `kv-one-time-code-slot` (a box) and `kv-one-time-code-separator` (the pattern's dash: a 12px cell of `text`, no edge or fill, `aria-hidden`), with no new token and no modifier class. The Root renders `data-character-count` and `data-separator-count` from the pattern, and the theme reads them. The boxes (44px, 32px compact, shrinking to 32px) and dashes are drawn over the input only when the script has run (`data-ready`), the pattern has 4 to 10 characters and at most 2 dashes, the browser isn't in forced colours and the row fits (`(2.5 × characters + 1.25 × dashes − 0.5)rem`). Otherwise the theme shows a plain input as wide as the pattern, dashes included, with the same value and focus. A pattern that can hold letters gets Plex's dotted zero. The caret is a static bar. The selectors of `kv-input` also style `kv-one-time-code-input`.
