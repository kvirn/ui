OneTimeCode (Plan 0014, Phase 3, ADR-0033). A code from a text message, an email or an authenticator app, shown as a row of boxes over one native `<input>`: SMS autofill, password managers, paste, dictation and undo work on the one field, and the boxes only draw its value, caret and selection.

- `@kvirn-ui/react`: `OneTimeCode.Root`, `.Input` and `.Slot` (also `OneTimeCodeRoot`, `OneTimeCodeInput`, `OneTimeCodeSlot`) and the hook `useOneTimeCode({ length, characters, value, defaultValue, onValueChange, onComplete, disabled, announceRejections, messages })`, which returns `rootProps`, `inputProps`, `getSlotProps(index)`, `slots` (`{ character, isFilled, isActive, caret, isSelected }`), `isComplete` and `isReady`. The input is `type="text"` with `autocomplete="one-time-code"`, no `maxlength`, and the `masks.oneTimeCode` mask (a pasted `123 456` or "Your code is 123456" ends as `123456`). The slots are `aria-hidden` and take `data-filled`, `data-active`, `data-caret`, `data-selected` and `data-invalid`; the root takes `data-ready`, `data-complete`, `data-invalid` and `data-disabled`. Nothing moves focus or submits: `onComplete(value)` is a callback only. The component adds no strings. Types: `OneTimeCode*Props`, `OneTimeCodeState`, `OneTimeCodeSlotState`, `OneTimeCode*PartProps`, `UseOneTimeCodeOptions`, `UseOneTimeCodeResult`. Development warnings: a Slot or Input outside a Root, a Slot with an index outside the code, an Input with no accessible name, and an Input in a Field without a description.
- `@kvirn-ui/theme`: styles for `kv-one-time-code`, `kv-one-time-code-input`, `kv-one-time-code-slot` and the modifier `kv-one-time-code--grouped`, with no new token. The boxes (44px, 32px compact, shrinking to 32px) are drawn over the input only when the script has run (`data-ready`), the browser isn't in forced colours and the row fits (2.5rem a character); otherwise the theme shows a plain numeric input with the same value and focus. The caret is a static bar. The selectors of `kv-input` now also style `kv-one-time-code-input`.
