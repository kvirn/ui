Add the pattern classes for the site chrome (`kv-page-frame`, `kv-site-header`, `kv-mega-menu`, `kv-site-footer`), in `patterns.css` imported by `theme.css`. The same file ships the navigation and promotion classes: the promotion blocks (`kv-hero`, `kv-nav-tiles`, `kv-service-link`), `kv-section-navigation`, and the site alert, cookie consent and page tools classes (`kv-site-alert`, `kv-cookie-consent`, `kv-page-tools`).
