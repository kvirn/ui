Add `List` (`List.Root`, `List.Item`; `as` `ul` or `ol`, `marker` `none`, `bullet` or `decimal`, `gap`), the one native list for link lists and other short lists. Without a marker it adds `role="list"`, so WebKit keeps the list role. `theme.css` styles `kv-list`, `kv-list--bullet`, `kv-list--decimal` and `kv-list--gap-2|6|8`.
