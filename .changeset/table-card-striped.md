Table: two opt-in modifiers on `Table.Root`, `kv-table--card` (a `border-subtle` frame with `radius-md` corners, rounded on the corner cells) and `kv-table--striped` (the `surface` fill on every second body row; a selected row keeps `primary-subtle`). The default table is unchanged: no frame, no stripes (Plan 0068).

Table: `--kv-table-cell-font-size-default` sets the table text size (the body size when unset), for example `0.875rem` for dense reference tables.
