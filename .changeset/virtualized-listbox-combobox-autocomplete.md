Virtualized Listbox, Combobox and Autocomplete (Plan 0026): a `virtualize` option for a flat list of thousands of options.

- `@kvirn-ui/core`: `createListVirtualizer(options)`, a wrapper of TanStack Virtual (the only place that imports it) for a vertical list: `getVirtualItems()`, `getSegments()` (the rendered items and the gaps between them, which add up to `getTotalSize()`), `getTotalSize()`, `isRendered(index)`, `scrollToIndex(index, { align })`, `measureElement(element)`, `setOptions(options)` and `mount()`. `getRequiredIndexes()` names the indexes that are always rendered, even when out of view (the active, chosen and focused item), so `aria-activedescendant` and focus never point at an element that isn't in the DOM. Types `ListVirtualizer`, `ListVirtualizerOptions`, `VirtualListItem` and `VirtualSegment`, and `defaultListOverscan`.
- `@kvirn-ui/react`: `virtualize?: boolean | { estimateSize?: number; overscan?: number }` on `Listbox.Root`, `Combobox.Root`, `Autocomplete.Root`, `useListbox`, `useCombobox` and `useAutocomplete`. Off by default. The popup renders only the options in view plus the active and the chosen option, inside one sizer element (`kv-listbox-virtual-sizer`) in the `role="listbox"` element, which is the scroll element and has `data-virtualized`. Every rendered option has `aria-setsize` and `aria-posinset`, Home, End, Page Up, Page Down, the arrows and typeahead work on the whole list, and a key move scrolls to the active option before `aria-activedescendant` points at it. `groups` are not virtualized (they render in full, with a development warning), and the native `<select>` ignores `virtualize`. Give the list a height limit and `overflow-y: auto` (the default theme does). Filter or paginate first: options that aren't rendered can't be found with find in page or printed. The list part props gain `ref` and `data-virtualized`, and `UseListboxResult` and `UseComboboxResult` gain `virtualization`. Types `ListboxVirtualizeOption`, `ListboxVirtualization`, `ListboxVirtualSizerPartProps` and `ListboxVirtualOptionPartProps`.
